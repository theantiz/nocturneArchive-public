# Nocturne

A minimal, focused personal blog built with Next.js and TypeScript.

Overview

Nocturne renders Markdown articles from the `content/` folder using small, reusable React components. It's intentionally simple — designed for long-form reading with minimal distractions.

Highlights

- Next.js (App Router)
- Markdown content with frontmatter
- Lightweight component library in `components/`
- Reading-focused UX (progress bar, typography helpers)
